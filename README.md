# ערים מעוררות השראה

## [לפתיחת האפליקציה ב-GitHub Pages](https://anat1969.github.io/CitiesExplorer/)

כתובת חלופית ב-Vercel: [cities-explorer-navy.vercel.app](https://cities-explorer-navy.vercel.app)

מקרי בוחן של רחובות, כיכרות ושכונות מהעולם ומישראל, מסודרים לפי הבעיה התכנונית שהם פתרו.
מתארים את האתר שלך, ומקבלים את המקרים הקרובים, אסטרטגיה מדורגת והסיכונים שכדאי לבדוק.

| כניסה ישירה | |
|---|---|
| [הפרויקט שלי](https://cities-explorer-navy.vercel.app/?view=project) | השוואת האתר שלך למקרים, אסטרטגיה ותדריך |
| [מטריצת המהלכים](https://cities-explorer-navy.vercel.app/?view=moves) | 40 מהלכים מול 9 בעיות |
| [מפה וזמן](https://cities-explorer-navy.vercel.app/?view=map) | כל המקרים על המפה ועל ציר הזמן |
| [כל המקרים](https://cities-explorer-navy.vercel.app/?view=all) | 54 מקרי בוחן, 8 מישראל |

## פיתוח

```bash
npm install
npm run dev
npm run build
npx vite preview --port 4173 & node tests/e2e.mjs
```

מבנה, החלטות ומה שלמדנו בבנייה: `CLAUDE.md`.
